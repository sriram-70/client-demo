ETRAM — WEBSITE CONCEPT
========================

This is a client-shareable static concept built around Etram's positioning:
weddings, corporate events and cultural performances.

Included:
- index.html
- assets/ (client-provided performance imagery)

Open index.html in a browser to view locally.
For a public demo, upload the folder to Vercel, Netlify, GitHub Pages, or any static host.

The imagery in assets/ was supplied in the conversation by the client/project owner.
